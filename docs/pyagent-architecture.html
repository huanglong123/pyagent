1. Project overview

PyAgent is a Python AI coding agent harness built with LangGraph and LangChain, designed by referencing the architecture of pi-mono (a TypeScript monorepo). It uses a 4-layer architecture with 9 packages, providing a unified LLM provider abstraction, a stateful agent loop with tool-calling, multiple CLI modes, a terminal UI, and a client-server system for remote sessions.

2. Layered architecture

The project follows pi-mono's 4-layer separation. Each layer depends only on the layers below it, ensuring clean dependency direction and modularity.

4. Foundation layer

pyagent-ai Foundation

Unified LLM provider abstraction via LangChain. Provides a ProviderConfig that selects the backend (OpenAI, Anthropic, Google, Ollama) and returns a LangChain BaseChatModel instance.

Key files: 
packages/ai/src/pyagent_ai/
  providers.py    # ProviderConfig + get_chat_model() factory
  models.py       # MODEL_REGISTRY - 12 known models with metadata
  streaming.py    # StreamHandler + StreamChunk
Core API: 
from pyagent_ai import ProviderConfig, ProviderType, get_chat_model

config = ProviderConfig(provider=ProviderType.OPENAI, model="gpt-4o-mini")
model = get_chat_model(config)  # Returns ChatOpenAI instance

# Supports invoke() and stream()
response = model.invoke([{"role": "user", "content": "Hello"}])

pyagent-tui Foundation

Terminal UI built with Textual. Provides an interactive chat interface with message history, input box, and streaming response display.

Key files: 
packages/tui/src/pyagent_tui/
  app.py      # AgentApp - main Textual App
  widgets.py  # MessageWidget, ToolCallIndicator, StatusBar
  screens.py  # HelpScreen (modal)

pyagent-protocol Foundation

Wire format for all communication. Uses Pydantic models for message types and cbor2 for binary serialization (matching pi-mono's CBOR protocol).

Key types: 
from pyagent_protocol import Message, MessageRole, ToolCall, ToolResult
from pyagent_protocol import SessionRequest, SessionResponse, SessionEvent
from pyagent_protocol import serialize, deserialize

# CBOR serialization
msg = Message(role=MessageRole.USER, content="Hello")
data = serialize(msg)      # bytes
msg2 = deserialize(data, Message)  # Message

5. Runtime layer

pyagent-agent Runtime

The core agent runtime. Uses LangGraph StateGraph to implement the ReAct pattern: reason → act (tool call) → observe (tool result) → loop.

Key files: 
packages/agent/src/pyagent_agent/
  state.py     # AgentState (TypedDict) - messages, tools, iteration count
  tools.py     # ToolRegistry + ToolSpec - tool registration and execution
  nodes.py     # call_model, should_continue, execute_tools - graph nodes
  graph.py     # build_agent_graph() - compiles the StateGraph
  session.py   # AgentSession - high-level orchestration API
Graph topology: 
START -> call_model -> should_continue
                              |
                    +---------+---------+
                    |                   |
                 "tools"             "__end__"
                    |
              execute_tools
                    |
                    v
              call_model (loop back)
Usage: 
from pyagent_agent import AgentSession, ToolRegistry

session = AgentSession(model_config=config)
session.register_tool("read_file", "Read a file", my_read_fn)
response = session.run("What files are here?")

pyagent-client Runtime

Async remote session client using httpx. Connects to a pyagent-server instance and sends prompts over HTTP, supporting both blocking and streaming responses.

Core API: 
from pyagent_client import RemoteSession

client = RemoteSession("http://localhost:8765")
response = client.send_prompt("What is 2+2?")
# Streaming
for event in client.stream_prompt("List all files"):
    print(event)

6. Application layer

pyagent-coding-agent Application

The flagship CLI application. Provides three execution modes (mirrors pi-mono's coding-agent modes):

  • Pipe mode: single prompt → stdout (for scripting)
  • Interactive mode: REPL loop with rich markdown rendering
  • RPC mode: connect to a remote pyagent-server
Key files: 
packages/coding_agent/src/pyagent_coding_agent/
  __main__.py     # Entry point (python -m pyagent_coding_agent)
  cli.py          # typer CLI with all options
  modes.py        # run_pipe_mode, run_interactive_mode, run_rpc_mode
  tools/
    file_ops.py   # read_file, write_file, list_directory, file_exists
    shell.py      # run_command (subprocess with timeout)
CLI usage: 
# Pipe mode
python -m pyagent_coding_agent "What files are here?"

# Interactive mode
python -m pyagent_coding_agent

# Model selection
python -m pyagent_coding_agent -m claude-3-5-sonnet -p anthropic "prompt"

# RPC mode
python -m pyagent_coding_agent --rpc http://localhost:8765 "prompt"

# Disable tools
python -m pyagent_coding_agent --no-tools "Just answer this question"

7. Infrastructure layer

pyagent-server Infrastructure

FastAPI session server. Manages agent sessions, exposes REST endpoints, and supports NDJSON streaming.

Endpoints: 
GET  /api/health              # Health check
POST /api/session              # Create/continue session
POST /api/session/stream       # Stream events as NDJSON
GET  /api/session/{id}         # Get session history

pyagent-storage Infrastructure

SQLite persistence using SQLModel. Three tables: sessions, messages, tool_results.

Schema: 
sessions (id, created_at, updated_at, system_prompt, model_provider, model_name, temperature)
messages (id, session_id, role, content, name, tool_call_id, created_at, seq)
tool_results (id, session_id, tool_call_id, tool_name, arguments, result, is_error, created_at)

pyagent-evals Infrastructure

Evaluation framework. Run prompts through the agent and assert on results.

Usage: 
from pyagent_evals import EvalRunner, EvalCase

runner = EvalRunner(config=ProviderConfig(...))
runner.add_case(EvalCase(
    name="math",
    prompt="What is 2+2?",
    assert_fn=lambda r: "4" in r,
))
results = runner.run()
EvalRunner.print_report(results)

8. Agent data flow

The following diagram shows how a user prompt flows through the system:

create_initial_state()
LangGraph invoke
→
call_model node
→
LLM provider API
→
Tool calls?
→ yes
execute_tools node
→
loop back to call_model
Tool calls?
→ no
END
→
Extract assistant response
→
Render output

Detailed steps:

  1. User input: prompt arrives via CLI argument (pipe mode), REPL input (interactive mode), or HTTP POST (RPC mode)
  2. CLI parse: typer parses arguments, builds ProviderConfig from --model/--provider flags
  3. Mode route: modes.py selects pipe/interactive/rpc handler
  4. AgentSession.run(): creates AgentState with model, tools, system prompt, and history
  5. LangGraph invoke: compiled StateGraph executes the node sequence
  6. call_model: binds tools to the LangChain model, calls model.invoke(messages)
  7. should_continue: checks if the last message has tool_calls and iteration count is under max
  8. execute_tools: runs each tool call via ToolRegistry.execute(), appends results as tool messages
  9. Loop: feeds results back into call_model for the next LLM turn
  10. Output: extracts the final assistant message, renders via rich markdown (interactive) or prints to stdout (pipe)

11. Quick start

# 1. Create virtual environment
cd D:\projects\pyagent
python -m venv .venv
source .venv/Scripts/activate  # Windows Git Bash

# 2. Install all packages (editable mode)
pip install -e packages/protocol -e packages/ai -e packages/agent \
  -e packages/storage -e packages/coding_agent -e packages/tui \
  -e packages/client -e packages/server -e packages/evals

# Or use the dev setup script
python scripts/dev_setup.py

# 3. Set your API key
export OPENAI_API_KEY="sk-..."

# 4. Run the agent (pipe mode)
python -m pyagent_coding_agent "List files in the current directory"

# 5. Interactive mode
python -m pyagent_coding_agent

# 6. Use a different model/provider
python -m pyagent_coding_agent -m claude-3-5-sonnet -p anthropic "prompt"

# 7. Start the server (for RPC mode)
python -c "from pyagent_server import app; app.run()" # or uvicorn
# Then in another terminal:
python -m pyagent_coding_agent --rpc http://localhost:8765 "prompt"
